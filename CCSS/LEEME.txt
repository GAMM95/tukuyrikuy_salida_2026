TUKUYRICUY 2026 - CCSS (SECUNDARIA)

Archivos: config_ccss.py, procesamiento_ccss.py, reportes_ccss.py, main_ccss.py.

Ubicación sugerida: D:\Python\tukuyrikuy_salida_2026\CCSS\
Excel de entrada:
CCSS\resources\RESULTADOS_PERSONAL_SOCIAL_CCSS.xlsx

Se usa la hoja RESULTADOS si existe; si no, la primera hoja.
Columnas requeridas: NIVEL, GRADO, V1...V16.
El procesamiento filtra SECUNDARIA, grados 1 a 5.

Distribución:
- Históricas: P1-P6 (6). INICIO 0-2; PROCESO 3-4; LOGRADO 5-6.
- Espacio: P7-P11 (5). INICIO 0-2; PROCESO 3-4; LOGRADO 5.
- Recursos económicos: P12-P16 (5). INICIO 0-2; PROCESO 3; LOGRADO 4-5.

IMPORTANTE: en la indicación original, Espacio tenía un umbral de LOGRADO <=6,
pero la matriz de respuestas muestra COMP_2_TOTAL=5. El código usa el máximo
real de 5 preguntas para evitar clasificaciones imposibles.

Se asigna peso igual a las tres competencias (1/3 cada una).
Los umbrales globales de 50 y 75 puntos son provisionales y configurables
en config_ccss.py (LIMITE_GLOBAL_INICIO y LIMITE_GLOBAL_PROCESO).

Dependencias: pip install pandas openpyxl
Ejecutar: python main_ccss.py

Salidas:
- BASE_PROCESADA_CCSS_SECUNDARIA.xlsx
- REPORTE_GENERAL_CCSS_SECUNDARIA.xlsx
- REPORTES_INSTITUCIONES_CCSS_SECUNDARIA.zip
