TUKUYRICUY 2026 - CIENCIA Y TECNOLOGÍA

ARCHIVOS
- config_cyt.py: configuración de rutas, competencias, pesos y niveles.
- procesamiento_cyt.py: lee RESULTADOS_CIENCIA_TECNOLOGIA.xlsx y calcula resultados.
- reportes_cyt.py: genera el reporte consolidado y reportes por institución.
- main_cyt.py: ejecuta todo el proceso.

INSTALACIÓN
1. Copia la carpeta CYT dentro de D:\Python\tukuyrikuy_salida_2026\
2. Coloca RESULTADOS_CIENCIA_TECNOLOGIA.xlsx en CYT\resources\
3. Instala dependencias en tu entorno virtual:
   pip install pandas openpyxl numpy
4. Ejecuta:
   python CYT\main_cyt.py

COMPETENCIAS Y PREGUNTAS
- Indaga: P1-P6. Inicio 0-2; Proceso 3-4; Logrado 5-6.
- Explica: P7-P12. Inicio 0-2; Proceso 3-4; Logrado 5-6.
- Diseña: P13-P16. Inicio 0-2; Proceso 3; Logrado 4.

PESOS Y RESULTADO GLOBAL
Las tres competencias tienen el mismo peso (1/3 cada una).
El nivel global usa provisionalmente: Inicio <=50%; Proceso <=75%; Logrado >75%.
Si tus módulos anteriores usan otros umbrales globales, modifica UMBRAL_GLOBAL_INICIO
y UMBRAL_GLOBAL_PROCESO en config_cyt.py.

SALIDAS
CYT\resultados\BASE_PROCESADA_CYT.xlsx
CYT\resultados\REPORTES_CYT\REPORTE_GENERAL_CYT.xlsx
CYT\resultados\REPORTES_CYT\REPORTES_CYT_POR_INSTITUCION.zip
Además, se genera una carpeta con un Excel por institución.
